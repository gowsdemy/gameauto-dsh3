# GM-All-In-One · GameMale 论坛签到（本地版）

> **本仓库是对 [Highboed/GM-All-In-One](https://github.com/Highboed/GM-All-In-One) 的修改/衍生版本。**
> 原项目是**纯 GitHub Actions 云端自动签到**；本版本因论坛新增了 **Cloudflare 人机验证**（会拦截云数据中心 IP），
> 改为 **在你的 Windows 电脑上、用真实浏览器（Edge/Chrome）本地运行**。签到/抽奖/互动/资产记录/邮件等核心功能保持一致。

---

## 它能做什么

- **全日常覆盖**：自动完成基础签到、插件抽奖、空间串门(3次)、打招呼(3次)、日志表态(10次)、你画我猜出题。
- **资产看板与对比**：抓取金币、血液、旅程、追随、知识、咒术、堕落、灵魂，自动和昨日金币对比。
- **可选邮件通知**：把当天结果发到你的邮箱（邮箱留空则自动跳过发信）。
- 全部走论坛底层接口，快且稳定；`config.env` 不提交、不上传。

---

## 快速上手

**需要**：Windows 电脑 + 已安装 Python 3.10+（[官网下载](https://www.python.org/downloads/)，安装时勾选 *Add Python to PATH*）。
浏览器方面，脚本会**自动检测 Edge / Chrome**（Chromium 系都行）；装了任意一个即可。

1. 解压本压缩包到某个文件夹（建议不含中文和空格，如 `C:\gameauto`）。
2. 复制 `config.env.example` 为 `config.env`，用记事本填好：
   ```
   USERNAME=你的论坛用户名
   PASSWORD=你的论坛登录密码
   ```
   邮件可选（`SMTP_HOST` / `MAIL_USER` / `MAIL_PASS` 留空则不发邮件）；详细说明见 `config.env.example` 文末。

### 想每天自动签到（推荐）：双击 `配置计划任务.bat`
- 它会读取 `config.env` 里的 `AUTOTIME`（默认 `00:10`），创建"**每天自动运行**"的计划任务，
  并**立即先运行一次**。
- **第一次运行**会弹一次浏览器窗口，**若出现"请进行人机验证"请点一下验证框**；
  随后会保存会话，**以后每天都会静默自动运行**（不弹窗、不用点验证、免登录），完成后弹一个"签到完成"通知。
- 不想每天自动跑了：双击 **`卸载计划任务.bat`** 一键卸载（只删任务，不删文件）。

### 想手动运行：双击 `运行签到.bat`
- 首次会自动安装依赖（较慢），之后同上（有会话就静默，没有就弹一次窗口让你点验证）。
- 运行结束窗口**保留显示结果**：按任意键关闭，或 10 秒后自动关闭。

## 变更说明（相对原仓库）

| 位置 | 说明 |
| --- | --- |
| 运行方式 | 云(GitHub Actions) → **本地 + 真实浏览器**（绕过 Cloudflare 对数据中心 IP 的拦截） |
| 账号配置 | 仓库 Secrets → **本地 `config.env`** |
| 定时触发 | Actions 定时任务 → **`配置计划任务.bat` 一键创建 Windows 计划任务**（时间由 `AUTOTIME` 决定） |
| 其它 | 邮箱可留空跳过；自动检测 Edge/Chrome；会话 cookie 本地持久化，之后免验证免登录 |

---

## 文件都是干什么的

| 文件 | 作用 |
| --- | --- |
| `运行签到.bat` | **手动运行**签到（双击这个） |
| `配置计划任务.bat` | **一键配置每天自动运行**（双击这个） |
| `卸载计划任务.bat` | 一键卸载计划任务（只删任务，不删文件） |
| `setup_task.ps1` / `remove_task.ps1` | 上面两个 `.bat` 内部调用的脚本，用户不用管 |
| `gamemale_v2.py` | 主程序（干活的核心） |
| `config.env.example` | 配置模板：复制为 `config.env` 后填写 |
| `requirements.txt` | 依赖清单 |
