# GameMale 论坛自动签到（本地版）

一个帮你**每天自动**在 GameMale 论坛完成「登录 → 签到 → 抽奖 → 小互动」的小工具，
还能把当天的金币等变化**保存下来看**，并且**可选**用邮件把结果发给你。

> 一句话：**你想每天都签到领奖励，但懒得手动点。这个小工具替你每天自动做。**

---

## 一、先弄清楚：这个脚本是干什么的？

- 每天自动用你的账号登录 GameMale 论坛。
- 自动完成：签到、抽奖、访问别人空间打个招呼、给日志表态、玩一次"你画我猜"。
- 把当天你的金币、血液、旅程、灵魂等资产变化记录下来（生成 `gold_record.txt`）。
- 可选：把这些结果用邮件发给你。

**它一次运行一般 1 分钟左右，全自动，不需要你一直盯着。**

---

## 二、需要准备什么？（很简单）

| 需要 | 说明 |
| --- | --- |
| **一台 Windows 电脑** | 运行环境 |
| **已安装 Microsoft Edge** | 就是 Windows 自带的 Edge 浏览器（不用额外装插件） |
| **已安装 Python 3.10 或更高** | 免费，官网 https://www.python.org/downloads/ 下载，安装时**勾选“Add Python to PATH”** |
| **一个 GameMale 论坛账号** | 你需要注册的账号和密码 |

> 为什么要用**你电脑上的 Edge**？因为论坛现在加了「请进行人机验证」（Cloudflare），会**拦云服务器**（比如 GitHub Actions），只有你**手机/家里的网络 + 真实浏览器**才放行。所以我们让你在自己电脑上跑，才能通过验证。

---

## 三、开始使用（照着做就行）

### 第 1 步：解压
把下载到的压缩包解压到电脑上，建议放到一个**不含中文、不含空格**的路径，比如：
`C:\gameauto`

### 第 2 步：填你的账号
在该文件夹里，找到 `config.env.example`，**复制一份**，把副本重命名为 `config.env`（去掉后面的 `.example`）。
用**记事本**打开 `config.env`，改成你自己的：

```
USERNAME=你的论坛用户名
PASSWORD=你的论坛登录密码
```

> 这两项是**必填**的。下面的 SMTP 邮箱是**可选的，先不用管**。

### 第 3 步：双击运行
双击 `run_local.bat`。
- 第一次运行会**自动安装所需组件**，较慢（1–3 分钟），请耐心等。
- 之后会弹出一个 **Edge 浏览器窗口**，在加载论坛。
  - 如果窗口里出现「请进行人机验证」，**用鼠标点一下那个验证框**即可。
  - 有时会自动通过，那就更省事。
- 看到窗口里打印「=== 所有作业同步执行完毕 ===」就成功了。
- 你的金币等结果也会显示在窗口里，并保存到 `gold_record.txt`。

## 四、想要每天自动运行？（推荐）

按下面 5 步设置「每天自动跑」：

1. 按键盘 **Win 键**，搜索并打开 **任务计划程序**。
2. 右侧点 **创建任务**。
3. 「常规」页：名称随便填，比如 `GameMale 签到`。
4. 「触发器」→ 点 **新建** → 选好你想要的**每天时间**（比如 00:20 和 14:40 各一个），确定。
5. 「操作」→ 点 **新建** →
   - 「程序或脚本」填：`cmd`
   - 「添加参数」填：`/c "C:\gameauto\run_local.bat"`（注意把路径换成你自己的）
6. 「条件」页：**取消勾选**「只有在计算机使用交流电源时才启动」。
7. 点 **确定** 保存。

之后电脑到点就会自动运行，并把结果发到你的邮箱（如果填了邮箱）。

## 五、想收到邮件报告？（可选）

如果你想让脚本把结果发到你的邮箱，在 `config.env` 里再填这三项：

```
SMTP_HOST=smtp.qq.com          # 用你发件邮箱对应的服务器地址（qq/163/gmail 等）
MAIL_USER=你的发件邮箱@qq.com
MAIL_PASS=你的SMTP授权码        # 不是邮箱登录密码！在邮箱设置里开启SMTP后生成授权码
MAIL_TO=                       # 收件邮箱；留空默认发给发件人自己
```

> **这三项里只要有一项为空，脚本就自动跳过发信**，其它任务照常完成，不影响使用。
> 如果你暂时不想收邮件，把这三项留空即可。

**怎么拿授权码？**（不是邮箱密码！）
- QQ 邮箱：网页版 → 设置 → 账户 → 开启 SMTP 服务 → 生成授权码。
- 163 邮箱：网页版 → 设置 → POP3/SMTP/IMAP → 开启 SMTP 服务 → 新增授权密码。

## 六、常见问题（小白也看得懂）

**Q1：双击 `run_local.bat` 一闪而过，没看到结果？**
可能 `config.env` 没填或没放对。确认同目录下有 `config.env`，且 `USERNAME`/`PASSWORD` 已填。
也可以右键 `run_local.bat` → 以管理员身份运行，或直接在 `cmd` 里运行它看报错。

**Q2：弹出窗口让我点「人机验证」？**
正常现象，点一下验证框就好。这是论坛的 Cloudflare 验证。

**Q3：用了很久没反应 / 停在某个地方不动？**
关掉窗口重试一次；若 `config.env` 没填邮箱又不想收邮件，确认那三项留空即可。

**Q4：提示缺少 Python / 找不到 py？**
去 https://www.python.org/downloads/ 装 Python 3.10+，安装时勾选「Add Python to PATH」，装完重开命令行再试。

**Q5：运行很慢？**
第一次要装依赖（ddddocr、playwright），之后会快很多。

**Q6：结果里的数字是什么意思？**
`金币`、`血液`、`旅程`、`追随`、`知识`、`咒术`、`堕落`、`灵魂` 是论坛里的几种资产/货币。脚本会记录当天金币并和昨天对比（显示 `较昨日 +X`）。

## 七、重要安全提醒

- `config.env` 里存着你的**真实账号密码**，**千万不要**把它发给别人、上传到网盘或被上传到公开仓库。
- 这个文件夹里的 `config.env.example` 是**空的模板**，不含任何个人信息，可以放心分发。
- 本工具只在你自己的电脑上运行，不会把账号上传到任何地方（除了登录时需要用你填的账号去论坛验证）。
