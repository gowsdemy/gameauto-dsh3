# GameMale 自动签到 · 本地运行说明（方案 B）

> 背景：论坛 www.gamemale.com 加了 Cloudflare「请进行人机验证」门，会拦截数据中心 IP（GitHub Actions 属于此类）。
> 你家的家庭宽带/手机 IP 属于 Cloudflare 信任的 IP，**不需要代理**，脚本用真实浏览器即可自动通过验证。
> 本说明适用于你在**自己电脑**上每天自动运行。

## 一、一次性准备

### 1. 安装 Python 3.10+（Windows）
到 https://www.python.org/ 下载安装，勾选 **Add Python to PATH**。

### 2. 下载本仓库代码
用 Git 克隆或直接下载 zip 到某个文件夹，例如 `C:\gameauto`。

### 3. 填写配置
把 `config.env.example` 复制一份，重命名为 `config.env`，用记事本打开，填入：
```
USERNAME=你的论坛账号
PASSWORD=你的论坛登录密码
SMTP_HOST=smtp.qq.com        # 用你发件邮箱对应的服务器（参考 README.md 对照表）
MAIL_USER=你的发件邮箱@qq.com
MAIL_PASS=授权码             # 不是邮箱密码，是 SMTP 授权码
MAIL_TO=                     # 留空则默认发给自己
```

### 4. 首次运行
双击运行 `run_local.bat`。它会自动创建环境、安装依赖、下载浏览器，然后登录签到。
首次运行成功后，会自动生成 `gold_record.txt`（用于每日金币对比）。

> `config.env` 含真实账号密码，属于敏感信息，**不要提交到公开仓库**（本仓库是私有仓库）。

## 二、设置「每天自动运行」（Windows 任务计划程序）

1. 按 Win 键，搜索「任务计划程序」并打开。
2. 点右侧「创建任务」。
3. 常规 页：
   - 名称填 `GameMale 签到`
   - 勾选「不管用户是否登录都要运行」（可选）
4. 触发器 页：点「新建」→ 设置你想要的每天时间，（建议北京时间 00:15 和 14:40 各一个，或你自己常用时间）→ 确定。
5. 操作 页：点「新建」→
   - 程序或脚本：`cmd`
   - 添加参数：`/c "C:\gameauto\run_local.bat"`
   - （把 `C:\gameauto` 换成你的实际路径）
6. 条件 页：取消勾选「只有在计算机使用交流电源时才启动」（电池/笔记本也运行）。
7. 确定保存。

保存后，电脑在该时间点会自动运行它；每次运行会自动把结果邮件发给你。

## 三、也可不设计划，手动运行
需要时直接双击 `run_local.bat`，或命令行：
```
cd C:\gameauto
run_local.bat
```

## 四、与 GitHub Actions 的关系
- 仓库照旧可保留（保存代码与金币记录）。
- 运行已经改由**你本地**触发；GitHub Actions 只作为代码仓库，不再负责定时跑。
- 若你更希望保留「云端自动跑」，请用**方案 A**（在 GitHub Actions 里配住宅代理），代码里已支持，只需填代理变量。
